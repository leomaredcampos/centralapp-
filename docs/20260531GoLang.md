## 1. Responsive Font Sizing Implementation

### Purpose
Implement adaptive font sizing that scales based on viewport dimensions while maintaining readability across different screen sizes and orientations.

### Implementation

#### Global CSS Configuration (`/frontend/src/app/globals.css`)
```css
body {
  font-size: clamp(8px, min(0.78vw, 1.2vh), 14px);
}

@media (orientation: landscape) {
  body {
    font-size: min(0.78vw, 1.2vh);
  }
}

@media (orientation: portrait) {
  body {
    font-size: 0.78vw;
  }
}
```

#### How It Works
- **`clamp(8px, min(0.78vw, 1.2vh), 14px)`**:
  - Minimum: 8px (prevents text from being too small)
  - Preferred: `min(0.78vw, 1.2vh)` (uses the smaller of viewport width or height)
  - Maximum: 14px (prevents text from being too large)
- **Landscape mode**: Uses both `vw` and `vh` to adapt to screen dimensions
- **Portrait mode**: Uses `vw` only for width-based scaling

#### Component-Level Implementation
All components use `clamp()` for responsive sizing:
```tsx
// Example from EmployeeInfoPanel.tsx
const lbl = "text-gray-500 leading-none text-[clamp(8px,0.78vw,16px)]";
const inp = "w-full p-[1px] border border-gray-300 outline-none text-[clamp(8px,0.78vw,16px)]";
```

### Benefits
- Automatic scaling based on screen size
- Maintains readability on both large and small displays
- Optimized for landscape orientation (common in business applications)
- Consistent sizing across all UI elements

## 2. Browser Zoom Prevention

### Purpose
Prevent users from accidentally zooming the application using Ctrl+/Ctrl- or mouse wheel, ensuring consistent UI appearance.

### Implementation

#### Viewport Meta Configuration (`/frontend/src/app/layout.tsx`)
```typescript
export const viewport: Viewport = {
  width: "device-width",
  initialScale: 1,
  maximumScale: 1,
  userScalable: false,
};
```

#### JavaScript Zoom Prevention (`/frontend/src/app/prevent-zoom.tsx`)
```typescript
"use client";

import { useEffect } from "react";

export default function PreventZoom() {
  useEffect(() => {
    const preventZoom = (e: WheelEvent | KeyboardEvent) => {
      if (e instanceof WheelEvent && e.ctrlKey) {
        e.preventDefault();
      }
      if (e instanceof KeyboardEvent) {
        if (
          (e.ctrlKey && (e.key === "+" || e.key === "-" || e.key === "=")) ||
          (e.ctrlKey && e.key === "0")
        ) {
          e.preventDefault();
        }
      }
    };

    document.addEventListener("wheel", preventZoom as EventListener, { passive: false });
    document.addEventListener("keydown", preventZoom as EventListener);

    return () => {
      document.removeEventListener("wheel", preventZoom as EventListener);
      document.removeEventListener("keydown", preventZoom as EventListener);
    };
  }, []);

  return null;
}
```

#### CSS Fixed Positioning (`/frontend/src/app/globals.css`)
```css
html {
  overflow: hidden;
  width: 100vw;
  height: 100vh;
}

body {
  width: 100vw;
  height: 100vh;
  overflow: hidden;
  position: fixed;
  top: 0;
  left: 0;
}
```

### Blocked Actions
- Ctrl + Plus (zoom in)
- Ctrl + Minus (zoom out)
- Ctrl + 0 (reset zoom)
- Ctrl + Mouse Wheel (zoom)
- Touch pinch-to-zoom (mobile)

### Benefits
- Consistent UI appearance across all user sessions
- Prevents layout breaking from zoom
- Professional fixed-size application behavior

## 7. Design Patterns Used

### Mother-Child Pattern
Each module has an `index.ts/go` file (mother) that exports functionality from child files:

```typescript
// Mother file (index.ts)
export { useSessionCheck } from './useSessionCheck';

// Child files
// - forceLogout.ts
// - checkSession.ts
// - periodicCheck.ts
```

### Custom Hooks Pattern (Frontend)
Encapsulate complex logic in reusable hooks:
- State management
- Side effects
- API calls
- Event handlers

### Module Pattern (Backend)
Organize related functionality into packages:
- Each package has a clear purpose
- Exported functions are used by parent modules
- Internal functions remain private
