## Changes Made Today: Removed Third-Party Auth Libraries

### Problem
Ang dating implementation ay gumagamit ng GitHub third-party libraries para sa authentication:
- `github.com/pquerna/otp` — TOTP generation & validation
- `github.com/boombuler/barcode` — QR code image generation
- `gopkg.in/gomail.v2` — Email sending
- `gopkg.in/alexcesaro/quotedprintable.v3` — Gomail dependency

### Solution
Pinalitan ng **pure Go built-in packages** — walang external dependency para sa auth logic.

### New Files Created

| File | Purpose | Go Packages Used |
|------|---------|-----------------|
| `utils/otp.go` | 6-character OTP generation | `crypto/rand`, `math/big` |
| `utils/email.go` | Send OTP via SMTP | `net/smtp`, `fmt`, `os` |
| `utils/totp.go` | TOTP secret gen, code gen, validation | `crypto/hmac`, `crypto/sha1`, `crypto/rand`, `encoding/base32`, `encoding/binary` |

### Updated Files

| File | Change |
|------|--------|
| `credential/login.go` | Removed `gomail` import, uses `utils.GenerateOTP()` and `utils.SendOTPEmail()` (goroutine) |
| `credential/totp.go` | Removed `pquerna/otp` import, uses `utils.GenerateTOTPSecret()`, `utils.GenerateTOTPURI()`, `utils.ValidateTOTP()`. No longer generates QR image — returns URI for frontend |
| `go.mod` | Removed `pquerna/otp`, `boombuler/barcode`, `gomail`, `quotedprintable` |

### Remaining Third-Party Dependencies (Required)

| Package | Reason |
|---------|--------|
| `github.com/lib/pq` | PostgreSQL driver — no built-in alternative in Go |
| `github.com/joho/godotenv` | .env file loading — convenience |

### QR Code Change
- **Before:** Backend generates QR image (base64 PNG) using `boombuler/barcode`
- **After:** Backend returns `uri` string, frontend uses external API:
  ```
  https://api.qrserver.com/v1/create-qr-code/?size=200x200&data={uri}
  ```

## Other Fix: App Module Not Showing

### Problem
Only 1 app module showing in dashboard instead of 2.

### Cause
Typo in `apptbl.appname`: value was `logisiticapp` but column in `appaccess` was `logisticapp`. The dynamic query failed silently.

### Fix
```sql
UPDATE apptbl SET appname = 'logisticapp' WHERE appname = 'logisiticapp';
```

### Additional Change
Added `ORDER BY buttonname ASC` to `HandleGetApps` query so apps display alphabetically.
